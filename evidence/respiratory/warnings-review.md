# Respiratory recording limitations

The seven historical full/restore native logs contained no warning, error, fatal or irreversible-state messages. The included 90-check report preserves the exact results; native logs and executables are not distributed.

The initial already-inspiring fragment was initially mislabelled as a complete breath. The corrected detector requires an observed plateau/rising predecessor (or genuinely zero first sample). All rows, native settings and tolerances are unchanged; each main branch contains 23 complete breaths.

Restore materializes source-defined identity=1 mechanics multipliers. Only these additional defaults are accepted; authored fields and effective settings remain unchanged. Numeric and event continuation is exact, not byte-identical full-state or action JSON.

The actual bilateral gas compartments are LeftLungPulmonary and RightLungPulmonary. Ambient reservoir volume is infinite by design and is excluded from finite pulmonary outputs; ambient pressure remains defined. Direct Current circuit access provides the resistance/compliance witnesses. The upstream lung-name string helper has a returning-reference-to-temporary defect; the checked numerical/export path does not use that string-rendering helper.

These are dynamic tidal and breathing-input trajectories, not forced spirometry or static-compliance measurements. Lower compliance changes resting volume as well as excursion. No clinical or learner validation is established.
