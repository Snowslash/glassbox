# Architecture

Vite builds a static multipage site: a project introduction at `index.html`, a lesson chooser at `lab.html`, an About/licences page and eight lesson/details HTML entrypoints under `app/`. Relative asset and recording URLs keep it usable at a project subpath. React is used for the shared estate header/theme and interactive lessons; there is no server-side simulation or application API.

Each lesson owns a pure state-transition model and a React view. Prediction initially reveals only the baseline. Playback advances the original sample index; seeking, replay and returning to prediction hide later trace points. Axes remain fixed across playback and branches. Comparison uses the same index in the matched recording rather than normalizing branches independently.

Pressure combines `model.mjs`, `presentation.mjs`, `Traces.jsx` and optional `ModelDetails.jsx`/`Inspector.jsx`. Oxygen uses `oxygen-model.mjs` and `OxygenApp.jsx`; content and delivery are native fields, with explicit dimensional conversion. Respiratory uses `respiratory-model.mjs` and `RespiratoryApp.jsx`; the columnar payload decodes into the original named quantities, with supplied observed driver-cycle boundaries.

Lesson-to-details links take a snapshot of the selected sample. Same-tab history retains the in-memory lesson state and returns paused. Query strings contain only safe selection parameters, not prediction or reflection text. A reload starts a fresh lesson. Only the estate theme preference persists.

Before a build, `publication-integrity.mjs` hashes every included evidence input against fixed source pins. Existing schema and gate validators then check rows, mappings, scientific constraints and review cross-references. Pericardial adds its own fixed SHA-256 approval gate in `pericardial-model.mjs` and `prepare-pericardial.mjs`, preserving all historical publication pins. Oxygen, respiratory and pericardial also enforce their fixed approvals in the browser. Invalid or missing recordings produce a refusal and explicit retry, never substitute data. Pressure retains its original runtime schema validation, with exact identity enforced at build time.

`verified-bundle.mjs` shares only ordered fetching, optional injected byte hashing, JSON decoding and cancellation checks. Each `*-bundle.mjs` descriptor owns its explicit URLs and calls its existing experiment validators; scientific pins remain in the unchanged models. Respiratory and pericardial refuse each changed file before parsing. Oxygen retains its three-digest gate and semantic review checks rather than acquiring a new review-byte pin. Pressure deliberately supplies no browser hash. A descriptor returns validated lesson-specific data, never a generic lesson state. Each React effect owns its AbortController, retry and state publication; it also checks the signal before displaying either success or failure. Cancellation stops subsequent work even if an injected transport or hash finishes late. There is no shared cache, fallback recording or new persistence.

The build copies evidence and verbatim licence files to the static output. The verifier compares source-to-output bytes and checks all HTML entrypoints and fonts. CSP permits self-hosted scripts, styles, fonts and data only; there is no analytics, account system or content autosave.
